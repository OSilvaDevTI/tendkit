# Security

Tendkit handles untrusted email, webhooks and attachments inside your app. If you find a way to:
- spoof a sender into someone else's account
- bypass webhook verification
- read another customer's tickets
- run script from an email

please report it privately through GitHub's **Report a vulnerability** button on the Security tab. Don't open a public issue.

We'll confirm within three working days. Fixes go out as a registry update and a security advisory. Since the code is copied into apps, the advisory names the affected files so you can diff them.
